# Student Dataset – Project 06

This project contains 20 fictional student records based on the supplied dataset. Department names and the distributions of levels, attendance percentages, and examination scores are retained, with the values rearranged.

## Files
- `student_dataset.csv` – the completed dataset.
- `create_dataset.py` – Python script to recreate the CSV.
- `README.md` – project documentation.

## Run
Install Python 3, then run `python create_dataset.py` in this folder.
